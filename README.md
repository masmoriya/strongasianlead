# Strong Asian Lead

Next.js archive site for Strong Asian Lead.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Notes

- Photos and logos live under `public/Photos` and `public/Logos and Assets`.
- Gallery pages read preserved photo folders directly.
- The site includes dark mode, cookie preferences, legal/accessibility pages, team pages, sitemap, and robots routes.
